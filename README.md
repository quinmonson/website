# website

Source for Quin Monson's academic website (Hugo + Hugo Blox + Pagefind, deployed to GitHub Pages).
Planned address: https://quinmonson.github.io/website/

See **UPDATING.md** to add papers, talks, or media links and to edit pages, and **WEBSITE_PRINCIPLES.md** for architecture.
Once GitHub Pages is turned on, pushing to `main` publishes automatically (GitHub Actions, about 2 minutes).
